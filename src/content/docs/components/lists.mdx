A list has three parts: a `ListView`, a **model** that holds the data, and a **delegate**, which is the template
for one row. This page is about the delegate. For when to use a list at all, see
[Showing collections](/patterns/collections/).

## Which delegate

Use a ready-made delegate. They already have the right height, padding, icon size, hover and focus effects, and
they work with keyboard and touch.

| A row shows… | Use | From |
| --- | --- | --- |
| One line of text, optional icon | `QQC2.ItemDelegate` | Qt Quick Controls |
| The same, with a checkbox, radio button or switch | `QQC2.CheckDelegate`, `RadioDelegate`, `SwitchDelegate` | Qt Quick Controls |
| A title and a subtitle | `KD.SubtitleDelegate` | Kirigami |
| Title, subtitle and a checkbox, radio button or switch | `KD.CheckSubtitleDelegate`, `RadioSubtitleDelegate`, `SwitchSubtitleDelegate` | Kirigami |

Prefer the Qt ones when one line is enough. The Kirigami delegates live in their own module:

```qml
import org.kde.kirigami.delegates as KD
```

### Something else

When no ready-made delegate fits, keep `QQC2.ItemDelegate` and replace only its inside, the `contentItem`.
You keep the background, highlight and keyboard handling. Kirigami offers `KD.TitleSubtitle` and
`KD.IconTitleSubtitle` as building blocks for this.

## Sizing rows correctly

A delegate must be told how wide it is. Always write it this way:

```qml
delegate: QQC2.ItemDelegate {
    required property string name

    width: ListView.view.width
    text: name
}
```

<Callout title="Not anchors" kind="warning">
  Do not use `anchors.fill: parent` or `anchors.left: parent.left` on a delegate. A delegate's parent is an
  internal item of the view, not the view, so anchoring to it gives wrong sizes. `ListView.view` always points
  at the list the row belongs to.
</Callout>

Declare the pieces of data the row needs as `required property`, as above. The view fills them in from the
model, and a typo in a name becomes an error instead of an empty row.

## Section headers

To group rows, tell the view which field to group by, and use `Kirigami.ListSectionHeader` for the heading:

```qml
ListView {
    section.property: "folder"
    section.delegate: Kirigami.ListSectionHeader {
        required property string section
        width: ListView.view.width
        text: section
    }
}
```

The model must already be sorted by that field; the view only draws a header where the value changes.

## Icons in rows

| Row | Icon size |
| --- | --- |
| One line of text | `iconSizes.smallMedium` (22 px) |
| Title and subtitle | `iconSizes.medium` (32 px) |

The ready-made delegates pick these for you. See [Icons](/foundations/icons/).

## Using list items well

- **Put the list directly inside a `Kirigami.ScrollablePage`**; it then needs no size or anchors. See
  [Pages](/components/page/).
- **Show an empty list as a [placeholder message](/components/placeholder-message/)**, not as blank space.
- **Buttons on a row** go at its trailing end, icon only, always visible, two at most.
- **Keep row text to one line** and let it elide (“…”) when it is too long. The delegates do this by default.

## Properties you will use

### On every delegate

| Property | Type | What it does |
| --- | --- | --- |
| `text` | string | The main line. |
| `icon.name` | string | Icon at the start of the row. |
| `highlighted` | bool | Draws the row as the current one. Usually bound to `ListView.isCurrentItem`. |
| `onClicked` | handler | Runs when the row is activated. |
| `width` | number | Set to `ListView.view.width`. |

### Extra on the Kirigami delegates

| Property | Type | What it does |
| --- | --- | --- |
| `subtitle` | string | The second, quieter line. |
| `checked` | bool | State of the checkbox, radio button or switch, on the delegates that have one. |

### Kirigami.InlineViewHeader

| Property | Type | What it does |
| --- | --- | --- |
| `text` | string | The title. |
| `actions` | list of actions | Buttons at the trailing end. |
