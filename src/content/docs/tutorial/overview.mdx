This tutorial builds the app above from an empty file. It has the same feature set as the well-known TodoMVC
exercise:

- add a task by typing and pressing Enter;
- tick a task off, and untick it again;
- delete a task, with a few seconds to undo;
- see how many tasks are left;
- show all tasks, only the open ones, or only the finished ones;
- remove all finished tasks at once;
- keep the list between sessions.

## What you need

- **Qt 6 and Kirigami**, installed from your distribution. On a system running KDE Plasma they are already there.
- **The `qml6` tool**, which runs a QML file directly. It is usually in a package named something like
  `qt6-declarative-tools`, `qt6-qtdeclarative-devel` or `qml6`.
- **KItemModels**, a small KDE library used from step 6 for filtering. It is part of KDE Frameworks and is
  present on any Plasma system; elsewhere the package is usually called `kitemmodels` or `kf6-kitemmodels`.
- **A text editor.** Kate has QML highlighting built in.

No compiler, build system or project setup is needed. A real app that you ship would have a small C++ or Python
launcher and a CMake file around it; the Kirigami tutorial linked at the bottom explains that part. Everything
you learn here carries over unchanged.

## How to follow along

Create an empty folder with one file in it, `main.qml`. Each step tells you what to add or change, and why.
After each step, run:

```sh
qml6 main.qml
```

Every step page ends with the complete file as it should look at that point, so if something does not work you
can compare, or simply copy it and carry on.
